# XYLO

Cash up front on the equities you keep.

[![Live site](https://img.shields.io/badge/site-usexylo.fun-145ef0)](https://usexylo.fun)

**Chain:** Solana
**CA:** pending

## Overview

XYLO is a landing site for a cycle-based pool: lock on-chain equities, collect an advance as each cycle opens, and stay exposed to the price.

## Features

- Live Solana market board and ticker (public DEX data, refreshed every minute)
- Register-driven slots: contract address, X and GitHub stay inert until stated
- Spring-based reveal, parallax hero, spotlight cards, reduced-motion support
